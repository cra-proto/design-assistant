# Link Writing

Use this skill when a parent workflow needs shared link-writing rules.

## Workflow
1. Preserve valid destination URLs for any links that remain.
2. Improve link text and surrounding sentence structure using the rules in the reference file.
3. Keep link behavior aligned with the parent workflow's output contract.

## Resources
- Read `references/link-writing-rules.json` for reusable link-writing rules.

## Output Boundary
- Do not change the parent workflow's output format.
- Do not invent destination details or new URLs.
